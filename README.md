Учебный проект: Сайт логистической службы «Lucky Bird»

Учебный многостраничный веб-сайт логистической компании, на котором расположены портфолио практических работ по дисциплине Верстка и прототипирование сайтов

Ссылка на опубликованный проект
Открыть сайт на GitHub Pages: https://uwnueq-art.github.io/lucky-bird/

Структура проекта
* `index.html` — главная страница компании
* `information.html` — информационный лонгрид «Переезд без стресса» с изображениями (`float`).
* `css/`
  * `style.css` — основные стили проекта (CSS-переменные `:root`, методология БЭМ, Flexbox, медиазапросы).
  * `task1.css` — стили для рисунка на чистом CSS (вариант 4 — трактор).
  * `task2.css` — стили для Flexbox-ролика с анимацией (вариант 2).
  * `task3.css` — стили для динамического теста.
* `tasks/` — раздел с лабораторными работами:
  * `task.html` — каталог заданий.
  * `task1.html` — Лабораторная работа 1: Рисунок на чистом CSS (Трактор).
  * `task2.html` — Лабораторная работа 2: Интерактивный Flexbox-ролик.
  * `task3.html` — Лабораторная работа 3: Динамический DOM-тест.
* `img/` — графические материалы проекта.
* `js/` — скрипты клиентской логики (интерактивный тест).
